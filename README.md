# bs9 工具使用文档

`bs9` 是一个用于文件编码/解码及打包管理的命令行工具，支持文本、HTML、JavaScript 等常见文件类型，并提供自定义字符表支持与 `bs9pack` 打包功能。

---

## 功能列表

| 编号 | 功能名               | 说明 |
|------|----------------------|------|
| `1`  | **Encode Files**     | 将普通文本类文件（如 `.txt`, `.html`, `.js` 等）编码为 `.bs9` 格式文件。 |
| `2`  | **Decode Files**     | 将 `.bs9` 文件还原为原始文件。<br>⚠️ 仅支持由**本程序当前版本**生成的有效 `.bs9` 文件。 |
| `3`  | **Show Data**        | 显示用于编码/解码的内部字符数据表（字符 ↔ 编码映射），便于调试或理解原理。 |
| `4`  | **Make bs9pack**     | 打包整个文件夹为 `.bs9pack` 归档文件。<br>要求：文件夹内含有效文件；<br>若为网站项目，**必须包含 `index.html`**。否则将识别为正常文件夹不给予自动启动的功能 |
| `5`  | **Unpack bs9pack**   | 解包 `.bs9pack` 文件到指定目录。<br>⚠️ 仅支持由**本程序当前版本**生成的有效 `.bs9pack` 文件。 |
| `6`  | **Encode Texts**     | 直接输入文本并实时编码为 bs9 格式字符串。<br>支持中文等 Unicode 字符（**但中文不转换为数字**，按原字符处理）。 |
| `7`  | **Decode bs9 Texts** | 输入 bs9 编码字符串，实时解码为原文本。<br>⚠️ 需确保编码版本与当前解码器兼容。 |
| `8`  | **Exit**             | 正常退出程序，返回退出码 `0`。 |

---

## ⚠️ 注意事项

- **版本敏感性**：`.bs9` 和 `.bs9pack` 文件的编码格式可能随程序版本变化。跨版本操作可能导致解码失败。
- **中文处理**：文本编码模式（功能 6/7）中，中文字符 **不进行数字转换**，而是按 Unicode 字符直接映射——请确保字符表包含对应字符或后备处理机制。
- **网站打包规范**：使用 `make bs9pack` 打包网站时，工具会检查根目录是否存在 `index.html`；若缺失，操作将被识别为普通文件夹。

---

## 🛠 示例场景

### 打包一个静态网站

```
> 选择功能(输入4) 4: make bs9pack  
> 输入文件夹路径: ./my-website/  
→ 检查到 ./my-website/index.html 存在  
→ 打包成功 → my-website.bs9pack
```

### 解码一段 bs9 文本

```
> 选择功能(输入7) 7: decode bs9 texts  
> 输入 bs9 字符串: "8733714022343838078710337140"  
→ 解码结果: "<h1>Hello</h1>"
```
